# Безопасность и модель угроз

Весь код открыт, чтобы вы могли проверить, что именно делает приложение. Ничего, кроме перечисленного ниже, оно не делает.

## Что где происходит

| Компонент | Что делает | Чего НЕ делает |
|---|---|---|
| `extension/` | редиректит `claude.ai`, `assets.claude.ai`, `assets-proxy.anthropic.com`, `api.anthropic.com` на ваш шлюз; добавляет `Authorization: Basic` **только к запросам на ваш шлюз**; подменяет отпечаток страницы | не читает страницы других сайтов (content-script только на домене шлюза), не отправляет данные никуда, кроме вашего шлюза; нет аналитики |
| `gateway/gateway.js` | подставляет session-cookies в запросы к `claude.ai`, вырезает идентифицирующие заголовки, переписывает URL | не отдаёт браузеру `Set-Cookie`, не шлёт cookies на другие хосты, не логирует cookies/query/тела |
| `server/Caddyfile.template` | TLS, basic_auth, передаёт имя пользователя шлюзу | не публикует шлюз наружу напрямую |

## Что проверено (аудит этого релиза)

Найдено и исправлено:

1. **Утечка реального IP клиента.** Шлюз вырезал лишь `X-Forwarded-For`; заголовки Cloudflare (`CF-Connecting-IP`, `CF-IPCountry`), `X-Real-IP`, `Forwarded`, `Via`, `CDN-Loop`, `True-Client-IP` уходили в claude.ai. Теперь вырезаются, плюс префиксы `cf-*`, `x-forwarded-*`, и др. Тест: `tests/gateway.test.js`.
2. **Session-cookie уходила на лишние хосты.** Cookies отправлялись и на `api.anthropic.com`. Теперь — только `claude.ai`/`www.claude.ai`.
3. **Токены в логах.** В лог попадал путь вместе с query (magic-link токены). Теперь query и fragment отрезаются.
4. **Cookie-jar.** Раньше сохранялись только cookies по regex имени и игнорировалось удаление. Теперь корректный jar: Max-Age/Expires, удаление при logout, лимиты размера/количества, атомарная запись, права `600`.
5. **Идентичность на публичных путях.** Путь ассетов без basic_auth теперь явно очищает `X-Remote-User` (клиент не может выбрать чужого пользователя).
6. **Лишняя поверхность.** Удалён удалённый Chromium (`/desktop`, CDP-порт с `--remote-allow-origins=*`) — он больше не нужен при self-service логине.
7. **Загрузки.** Тела запросов стримятся, а не буферизуются целиком в память.
8. **Контейнеры.** `cap_drop: ALL`, `no-new-privileges`, read-only FS и `pids_limit` у шлюза; Caddy только с `NET_BIND_SERVICE`.
9. Из ответов удаляются `Set-Cookie`, `Report-To`, `NEL`, `Alt-Svc` (браузер не должен общаться с инфраструктурой Anthropic/Cloudflare напрямую от имени домена шлюза).
10. `add-user.sh` создаёт валидный `{"cookies":[]}` вместо пустого файла.

Проверено без замечаний: защита от path traversal (`sanitizeUser` + проверка итогового пути), allow-list хостов (SSRF: `/p/<host>` принимает только 5 хостов, в т.ч. отсекает `169.254.169.254`, `claude.ai.evil.com`), отсутствие секретов в репозитории (домены/пароли — плейсхолдеры, `Caddyfile` и `cookies/` в `.gitignore`).

## Что видит каждая сторона

- **Claude** — IP вашего сервера, cookies пользователя, нормализованные заголовки (`Accept-Language: en-US`, фиксированный User-Agent) и (через расширение) отпечаток UTC / en-US.
- **Cloudflare** — реальный IP клиента и весь трафик в открытом виде (он терминирует TLS). Если это неприемлемо — не включайте оранжевое облако и принимайте риск обрывов у некоторых провайдеров.
- **Оператор сервера** — **полный доступ**: видит трафик и session-cookies всех пользователей. Это неизбежно для cookie-injecting прокси: **не используйте чужой шлюз для своего аккаунта и не давайте доступ тем, кому не доверяете.** Каждый пользователь = собственный аккаунт Claude.

## Известные ограничения

- **Basic_auth без rate-limit.** Используйте длинные случайные пароли (Caddy хранит bcrypt). При желании добавьте fail2ban/Cloudflare WAF.
- **Отпечаток:** подмена работает на странице и её фреймах; **не** покрывает Web/Service Workers, не меняет экран, шрифты, GPU/canvas, TLS/HTTP2-отпечаток браузера. «Чистый» здесь = нейтральные таймзона/язык/без геолокации/WebRTC, а не анонимность уровня Tor Browser. Зона-less строки дат (`"2026-01-01T10:00"`) трактуются как UTC; нестандартные парсеры могут отличаться.
- **ToS.** Использование Claude через прокси/для обхода региональных ограничений может нарушать условия Anthropic — это ваш риск.
- **Firefox:** временное дополнение снимается после перезапуска; для постоянной установки нужна подпись AMO. Скрипт отпечатка в Firefox проверен линтером (`web-ext lint`, 0 ошибок); автоматизированного рантайм-теста в Firefox в CI нет — только в Chrome.
- Сообщить об уязвимости: Issue в репозитории (без секретов в тексте).

## Как проверить самому

```sh
npm test                                    # тесты шлюза
npm run test:fingerprint                    # реальный Chrome, TZ=Europe/Moscow, --lang=ru-RU: до/после
./configure.sh claude.example.com           # собрать extension/dist/{chrome,firefox}
npm run lint:firefox
```
